
# Python `json` Module 

## The Core Idea: `s` = String

The naming convention is dead simple and consistent across the whole module:

| Function | I/O target | The `s` means... |
|---|---|---|
| `json.dump()` | **file** (stream) | — |
| `json.dumps()` | **string** | **s**tring |
| `json.load()` | **file** (stream) | — |
| `json.loads()` | **string** | **s**tring |

Think of it as: **no `s` = file handle, with `s` = in-memory string.** Same pattern as `pickle`.


## The Four Functions

### `json.dumps(obj, ...)` — Python → JSON string
Serializes a Python object to a JSON-formatted `str`. Nothing touches the disk.

```python
import json

data = {"name": "Vicky", "scores": [98, 87, 100], "active": True}

s = json.dumps(data)
# '{"name": "Vicky", "scores": [98, 87, 100], "active": true}'

# Pretty-print
s = json.dumps(data, indent=4)

# Compact (for network payloads)
s = json.dumps(data, separators=(',', ':'))
# '{"name":"Vicky","scores":[98,87,100],"active":true}'

# Sort keys (good for deterministic output / testing)
s = json.dumps(data, sort_keys=True)
```

### `json.dump(obj, fp, ...)` — Python → JSON file
Serializes a Python object as a JSON stream directly to `fp`, a file-like object supporting `.write()`.

```python
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=4)
```

### `json.loads(s, ...)` — JSON string → Python
Deserializes `s` (a `str`, `bytes`, or `bytearray` containing a JSON document) into a Python object.

```python
raw = '{"name": "Vicky", "active": true, "scores": [98, 87]}'
obj = json.loads(raw)
# obj["name"]   → "Vicky"  (str)
# obj["active"] → True     (bool, not the string "true")
# obj["scores"] → [98, 87] (list)
```

### `json.load(fp, ...)` — JSON file → Python
Deserializes from `fp`, a `.read()`-supporting text or binary file containing the JSON document.

```python
with open("config.json", "r", encoding="utf-8") as f:
    obj = json.load(f)
```


## Type Conversion Table

This is the mapping Python's `json` module uses:

| Python | JSON | Python |
|---|---|---|
| `dict` | `object {}` | `dict` |
| `list`, `tuple` | `array []` | `list` |
| `str` | `string` | `str` |
| `int`, `float` | `number` | `int` / `float` |
| `True` / `False` | `true` / `false` | `bool` |
| `None` | `null` | `None` |

**Gotcha:** `tuple` encodes as a JSON array, but decodes back as a `list`. Round-trip is lossy for tuples.

**Gotcha:** All dictionary keys are coerced to strings when encoding to JSON. If a dict has non-string keys, `loads(dumps(x)) != x`.


## Key Optional Parameters

All four functions share the same keyword-only parameters:

```python
# indent — pretty-print with N spaces
json.dumps(data, indent=2)

# sort_keys — deterministic output, great for tests/diffs
json.dumps(data, sort_keys=True)

# separators — (item_sep, key_sep), use (',', ':') for compact output
json.dumps(data, separators=(',', ':'))

# ensure_ascii — default True; set False to allow UTF-8 pass-through
json.dumps({"city": "北京"}, ensure_ascii=False)
# '{"city": "北京"}' instead of '{"city": "\\u5317\\u4eac"}'

# default — callback for non-serializable types
def serialize_path(obj):
    if isinstance(obj, Path):
        return str(obj)
    raise TypeError(f"Not serializable: {type(obj)}")

json.dumps({"path": Path("/tmp/x")}, default=serialize_path)
```


## Errors

`json.JSONDecodeError` (a subclass of `ValueError`) is raised when the data being deserialized is not a valid JSON document. It carries `.msg`, `.doc`, `.pos`, `.lineno`, and `.colno` for precise error location.

```python
try:
    json.loads("{bad json}")
except json.JSONDecodeError as e:
    print(e.msg, e.lineno, e.colno)
```


## Advanced: `object_hook` for Custom Decoding

```python
def as_complex(dct):
    if "__complex__" in dct:
        return complex(dct["real"], dct["imag"])
    return dct

json.loads('{"__complex__": true, "real": 1, "imag": 2}', object_hook=as_complex)
# → (1+2j)
```

This is the idiomatic hook for deserializing into custom types — relevant for your MES Knowledge Assistant and RCA Agent projects where you'll want structured Pydantic-like objects from JSON payloads.


## Combining with `pathlib` (previous topic)

```python
from pathlib import Path
import json

config_path = Path.cwd() / "config.json"

# Write
config_path.write_text(json.dumps(data, indent=2), encoding="utf-8")

# Read
obj = json.loads(config_path.read_text(encoding="utf-8"))

# Or use open() via Path directly
with config_path.open("w") as f:
    json.dump(data, f, indent=2)
```


## Mental Model (C++ bridge)

`json.dumps` / `json.loads` → think `std::ostringstream` / `std::istringstream`: serializing to/from an in-memory buffer.

`json.dump` / `json.load` → think writing/reading from a `std::ofstream` / `std::ifstream`: streaming directly to/from a file descriptor.
